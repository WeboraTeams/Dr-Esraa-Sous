# Security Policy

## 🔒 Security Measures
This repository contains a static frontend landing page hosted via GitHub Pages and enforced through SSL/TLS HTTPS encryption provided by Let's Encrypt.

* **No Backend / Database:** The website does not store or process sensitive patient personal health information (PHI) or medical records directly on this server.
* **External Dependencies:** All CDN scripts (Tailwind CSS, AOS, GLightbox, Font Awesome) are loaded via reputable Content Delivery Networks over secure HTTPS.

## 🛡️ Reporting Vulnerabilities
If you discover a security vulnerability or domain/DNS configuration issue regarding this site, please notify the development team:

* **Agency Support:** [Webora Team Agency](https://weborateams.com)
* **Primary Contact:** Create an issue on this repository or contact Webora Team Agency directly.

We appreciate responsible disclosure and will address valid reports promptly.# Security Policy
